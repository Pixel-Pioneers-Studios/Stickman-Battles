## Implementation Notes

- All files go in `audio/voices/` relative to the game root
- Recommended format: `.mp3` (best browser support) or `.ogg` (smaller, also fine)
- ElevenLabs export: 44.1 kHz, mono is fine for voice lines
- Lines marked `new` are optional — delete or skip any you don't want voiced
